WHAT THE SETUP DOES
================================================================================

Creates in AWS:
  ✓ OIDC Provider
    - URL: https://oidc.vercel.com/leoemaxie
    - Purpose: Allows AWS to trust Vercel tokens

  ✓ IAM Role (vercel-noa-app-role)
    - Purpose: Grants permissions to your app
    - Trust policy: Only Vercel OIDC can assume
    - Attached policies: DynamoDB + Bedrock access

  ✓ DynamoDB Table (noa-data)
    - Primary key: id
    - Billing: On-demand (pay per request)
    - Indexes: 3 Global Secondary Indexes

  ✓ Global Secondary Indexes
    - email-index: Query by email + type
    - doctorId-index: Query by doctor + type
    - patientId-index: Query by patient + type

  ✓ IAM Policies
    - DynamoDBAccess: Read/write table & indexes
    - BedrockAccess: Call AI models (Nova, Claude)

Sets in Vercel:
  ✓ AWS_REGION
  ✓ AWS_ACCOUNT_ID
  ✓ AWS_ROLE_ARN
  ✓ DYNAMODB_TABLE_NAME
  ✓ BEDROCK_REGION
  ✓ BEDROCK_NOVA_LITE_MODEL
  ✓ BEDROCK_NOVA_PRO_MODEL

IF SOMETHING GOES WRONG
================================================================================

Error: InvalidIdentityToken
  → Run setup script again: python scripts/setup-aws-oidc.py

Error: AccessDenied
  → Check IAM policies: aws iam list-role-policies --role-name vercel-noa-app-role

Error: ResourceNotFound
  → Check table: aws dynamodb describe-table --table-name noa-data

Error: NoCredentialsProvider
  → Verify env vars added to Vercel: vercel env list

Still broken?
  → Read TROUBLESHOOTING.md for detailed solutions
